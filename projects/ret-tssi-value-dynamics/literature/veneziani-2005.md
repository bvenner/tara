# Veneziani (2005) — Dynamics, Disequilibrium, and Marxian Economics: A Formal Analysis of Temporal Single-System Marxism

**Citation:** Veneziani, R. (2005). Dynamics, Disequilibrium, and Marxian Economics: A Formal Analysis of Temporal Single-System Marxism. *Review of Radical Political Economics*, 37(4), 517–529. DOI: 10.1177/0486613405280809

**Core claim:** A formal critique of TSSI. Methodologically: the TSSI lacks both a clear definition of equilibrium and a rigorous analysis of disequilibrium dynamics — "the dynamic framework is incomplete." Substantively: TSS claims are argued to be trivially obtained by assuming goods exchange at values apart from out-of-steady-state deviations; the TSSI proof of the falling rate of profit is argued to be tautological.

**Key points:**
- Generalizes Veneziani (2004, *Metroeconomica* 55:96–114) analysis of discrete-time TSS models to Freeman's (1996) continuous-time framework.
- Notes Freeman's main equations contain only *changes* in stocks; argues no rigorous definition of the MELT trajectory is provided.
- The critique implicitly issues a challenge: provide a well-posed dynamical system with a defined equilibrium and genuine stability analysis.

**Relevance to program:** This paper defines the precise gap the program fills. The RET formalism supplies exactly what Veneziani finds missing: a well-posed Cauchy problem (existence/uniqueness), a rigorous equilibrium concept (constant state of a dissipative balance-law system), and a genuine stability theory (entropy-Lyapunov methods). The program is, in this sense, a constructive answer to the Veneziani critique.
